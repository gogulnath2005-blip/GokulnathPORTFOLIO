# 🚀 A Gokulnath – Personal Portfolio Website

A modern, responsive personal portfolio website showcasing my technical skills, professional experience, projects, education, and contact information.

Designed with a futuristic dark theme, smooth animations, interactive elements, and a clean user interface to create a strong professional impression.

## 🌐 About the Project

This portfolio represents my journey as an Information Technology graduate and aspiring Software Engineer. It highlights my knowledge of Python, Java, JavaScript, React.js, Node.js, Express.js, and database technologies.

The website provides recruiters and visitors with an overview of my technical background and development projects.

## ✨ Features

- **Modern Hero Section** – Introduction, professional title, and opportunity status.
- **About Me** – Personal introduction and development interests.
- **Technical Skills** – Programming languages, frameworks, databases, and tools.
- **Professional Experience** – Internship experience at Tidal Neo and Valvenet Technologies.
- **Featured Projects** – Highlights of my development projects.
- **Education** – Academic qualifications and achievements.
- **Workshops & Certifications** – Training and workshop details.
- **Contact Section** – Email, LinkedIn, and phone information.
- **Interactive Animations** – Particle background, typewriter effect, scroll reveal, and animated counters.
- **Project Filtering** – Filter projects by category.
- **Responsive Design** – Layout adapts to desktop and mobile screens.
- **Back-to-Top Button** – Quick navigation to the top of the page.
