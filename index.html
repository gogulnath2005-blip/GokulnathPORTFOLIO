About

The engineer behind the code

A quick look at the journey, the strengths I lead with, and where I'm headed next.

I'm a final-year Information Technology student and full-stack developer based in Puducherry, India, with a track record of turning ideas into working software across Python automation, Java backends, and the MERN stack.

My journey started with curiosity about how systems talk to each other — that curiosity took shape through a human-following robot built on PID control logic, a voice-command assistant powered by NLP, and a tourism platform with full role-based access control. Each project pushed me from "it compiles" to "it's production-ready."

Internships at Tidal Neo and ValveNet Technologies sharpened that instinct further — writing automation scripts that cut manual work by 30%, and shipping three full-stack MERN applications in an Agile/Scrum environment with senior engineers reviewing every line.

I care about clean architecture, readable code, and software that solves a real problem for a real person — not just a checkbox on a feature list.
